# Brand

Whirl's mark and colors. Use them to point at Whirl, write about it, or
build on it. Please don't use them in ways that suggest your fork or product
_is_ Whirl.

## Logo

| File                        | Use it for        |
| --------------------------- | ----------------- |
| `logo/whirl-mark.svg`       | Light backgrounds |
| `logo/whirl-mark-white.svg` | Dark backgrounds  |
| `logo/whirl-mark-blue.svg`  | Brand moments     |

## Images

| File                 | Size        | Use it for                                         |
| -------------------- | ----------- | -------------------------------------------------- |
| `banner-dark.png`    | 1600 × 560  | README headers, dark                               |
| `banner-light.png`   | 1600 × 560  | README headers, light                              |
| `social-preview.png` | 1280 × 640  | Link previews (GitHub → Settings → Social preview) |
| `avatar.png`         | 1024 × 1024 | Profile pictures (GitHub org, socials)             |
| `app-icon-dark.png`  | 1024 × 1024 | App icon, ink                                      |
| `app-icon-blue.png`  | 1024 × 1024 | App icon, blue                                     |
| `palette.png`        | 1600 × 900  | The colors at a glance                             |

Editable sources for every image are in `src/`.

## Colors

| Name       | Hex       |
| ---------- | --------- |
| Whirl blue | `#0C82F2` |
| Sky        | `#38BDF8` |
| Ink        | `#141414` |
| Graphite   | `#202020` |
| Canvas     | `#F3F3F3` |
| Paper      | `#FFFFFF` |

Whirl blue leads, and Sky is its lighter partner. The product itself is
monochrome: ink on paper in light mode, paper on graphite in dark.
